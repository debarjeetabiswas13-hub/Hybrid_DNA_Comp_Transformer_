# HybridDNAComp: A Transformer-Based Framework for Lossless Reference-Free DNA Sequence Compression

**HybridDNAComp** is a deep learning-based framework for lossless DNA sequence compression. It uses a hybrid Transformer architecture with Rotary Positional Embeddings (RoPE), attention mechanisms, a latent representation bottleneck, adaptive probability modeling, and arithmetic coding to compress genomic sequences.

The framework aims to exploit long-range dependencies, repeated patterns, and contextual information in DNA sequences to improve compression efficiency while preserving exact sequence reconstruction.

---

## 1. Project Overview

The rapid growth of genomic data generated by next-generation sequencing technologies has created a need for efficient genomic data compression techniques.

Traditional compression algorithms, such as GZIP and Zstandard, provide general-purpose compression. However, genomic sequences contain specific patterns, repetitions, and statistical dependencies that can be exploited using specialized compression methods.

This project introduces **HybridDNAComp**, a Transformer-based framework designed for lossless, reference-free DNA sequence compression.

The proposed framework combines neural probability estimation with arithmetic coding to reduce the storage requirements of genomic sequences while maintaining exact reconstruction.

### Main Objectives

- Develop a Transformer-based architecture for DNA sequence compression.
- Capture local and long-range dependencies in genomic sequences.
- Utilize Rotary Positional Embeddings (RoPE) for positional information.
- Incorporate neural, pointer-copy, and memory-based probability distributions.
- Apply adaptive probability fusion for improved sequence modeling.
- Use arithmetic coding for lossless compression.
- Evaluate compression performance using standard compression metrics.

---

## 2. Key Features

- **Transformer-based architecture:** Learns contextual relationships in DNA sequences.
- **Rotary Positional Embeddings:** Incorporates positional information into attention mechanisms.
- **Attention mechanism:** Uses scaled dot-product attention.
- **Latent representation:** Projects the encoder representation into a compact latent space.
- **Hybrid probability modeling:** Combines neural prediction, pointer-copy, and memory-based distributions.
- **Adaptive gating:** Dynamically combines probability distributions.
- **Arithmetic coding:** Converts predicted probability distributions into a compressed bitstream.
- **Lossless reconstruction:** Targets exact recovery of the original DNA sequence.
- **Reference-free compression:** Does not require a reference genome for reconstruction.

## 3. Proposed Architecture

The proposed HybridDNAComp framework consists of the following major components:

1. DNA Sequence Preprocessing
2. Transformer Encoder
3. Rotary Positional Embedding (RoPE)
4. Latent Representation Bottleneck
5. Transformer Decoder
6. Hybrid Probability Modeling
7. Adaptive Probability Fusion
8. Arithmetic Coding

### Architecture Description

**1. DNA Sequence Preprocessing**

The input genomic sequence is processed and converted into numerical representations.

The nucleotide mapping used in the implementation is:

| Nucleotide | Numerical Representation |
|---|---:|
| A | 0 |
| C | 1 |
| G | 2 |
| T | 3 |

**2. Transformer Encoder**

The Transformer encoder extracts contextual information from DNA sequence segments. It consists of multiple attention blocks and feed-forward layers.

**3. Rotary Positional Embedding (RoPE)**

RoPE incorporates positional information into the attention mechanism, helping the model represent relationships between nucleotide positions.

**4. Latent Representation Bottleneck**

The encoder representation is projected into a lower-dimensional latent representation and then projected back to the model dimension.

**5. Transformer Decoder**

The decoder processes the learned representation to support contextual nucleotide probability estimation.

**6. Hybrid Probability Modeling**

The framework combines three probability sources:

- Neural probability distribution
- Pointer-copy probability distribution
- Memory-based probability distribution

**7. Adaptive Probability Fusion**

Adaptive gating combines the probability distributions to estimate the next nucleotide probabilities.

**8. Arithmetic Coding**

The estimated probability distributions are used by the arithmetic coder to encode the DNA sequence into a compact bitstream.

## 10. Compression and Decompression

### Compression

The compression procedure processes the input DNA sequence in chunks.

The first sequence segment is used as seed context. The remaining sequence is processed using the model to estimate nucleotide probability distributions. These distributions are then supplied to the arithmetic coder.

The encoded output is saved as:

```text
compressed.dnaac
```

### Decompression

The decompression procedure uses the encoded data, probability information, and seed context to reconstruct the original DNA sequence.

The reconstructed sequence is saved as:

```text
decompressed.fasta
```

### Important Implementation Note

In the current notebook, the compression function returns the encoded data and CDF information separately. The seed context and CDF information are also required by the decompression function.

Therefore, the generated `compressed.dnaac` file alone is not currently a self-contained, independently decompressible archive.

A portable compression format requires the necessary metadata, seed context, model/checkpoint information, and a reliable way to reproduce or store the coding probability information.

This functionality should be completed and tested before distributing the compressed file as a standalone archive.

## 11. Evaluation Metrics

The proposed framework is evaluated using the following metrics.

### 11.1 Bits Per Base (BPB)

Bits per base measures the average number of compressed bits required to represent one nucleotide.

\[
BPB = \frac{\text{Compressed Size (bits)}}{\text{Number of Bases}}
\]

A lower BPB indicates better compression efficiency.

### 11.2 Compression Ratio (CR)

Compression ratio measures the relationship between the original data size and the compressed data size.

\[
CR = \frac{\text{Original Size}}{\text{Compressed Size}}
\]

A higher compression ratio indicates better compression.

### 11.3 Reconstruction Accuracy

Reconstruction accuracy measures the percentage of nucleotide positions correctly recovered after decompression.

\[
Accuracy =
\frac{\text{Number of Correctly Reconstructed Bases}}
{\text{Total Number of Bases}}
\times 100
\]

For lossless compression, the reconstructed sequence must match the original sequence exactly.

### 11.4 Compression Time

Compression time measures the time required to encode the input genomic sequence.

### 11.5 Decompression Time

Decompression time measures the time required to reconstruct the original genomic sequence from the compressed representation.

## 14. Limitations

The current implementation has the following limitations:

1. **Nucleotide alphabet:** The preprocessing implementation supports only A, C, G, and T. Other ambiguous nucleotide symbols are removed.
2. **Computational cost:** Transformer-based sequence modeling can require substantial computational resources.
3. **Compression speed:** Neural probability estimation introduces computational overhead.
4. **Archive portability:** The current compressed output does not independently contain all information required for decompression.
5. **Experimental reproducibility:** The current notebook configuration and dataset split need to be aligned with the paper's reported experimental setup for complete reproducibility.
6. **Hardware dependency:** Training and compression performance may vary across GPU and CPU environments.
